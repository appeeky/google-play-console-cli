---
title: Scope
description: What this product includes and excludes.
---

## Included

Google Play **Android Publisher API v3** operations for:

- App edits, tracks, and deployments
- Store listings and images
- Reviews
- Testers
- Subscriptions, base plans, offers
- One-time products and purchase option offers
- Legacy in-app products
- Purchases and voided purchases
- Orders and external transactions
- Play Console users and grants
- APKs/AABs, deobfuscation, expansion files, internal sharing
- Generated and system APKs
- Data safety, app recovery, device tier configs

## Not included

| Area | Reason |
|------|--------|
| Play Developer Reporting / vitals | Separate Google API; not part of this product |
| GCS private report imports | Analytics/reporting pipeline, not Publisher publishing |
| Public Play Store scraping | Out of band from authenticated Publisher API |
| Enumerating all developer apps via Publisher | Not provided by Google; use the local `gps apps` registry |
| `appstorecatalog` | Not available in the supported googleapis Publisher client |
| `orders.reviewRefund` | Not available in the supported googleapis Publisher client |

If you need reporting or vitals, use Google’s Play Developer Reporting APIs separately.
