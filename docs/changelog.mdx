## 0.1.0

- Initial release of `@appeeky/google-play-store-core`, `gps`, and `gps-mcp`
- Android Publisher API v3 coverage for edits, deploy, tracks, listings/images, reviews, testers, monetization, purchases, orders, external transactions, users/grants, artifacts, generated/system APKs, internal sharing, data safety, app recovery, and device tier configs
- Shared operations registry (`GPS_OPS`) for MCP tools and `gps ops` / `gps call`
- Multi-account config (`gps accounts` / `gps apps`) with local app registry — Publisher API has no list-apps
- Local service-account authentication with `--read-only` and `--confirm` safeguards
